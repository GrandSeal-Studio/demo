德州扑克 WAP 互动 Demo

依据 PRD 00～15 与 Figma 原型制作。所有数据为示范数据，存于本机浏览器；同时打开前台与后台两个分页，后台的操作会即时反映到前台。
前台 · 主要体验
前台 WAP
手机浏览器版本（唯一的功能入口）。右侧导览面板可切换身份（游客 / 正式账号 / 俱乐部创建者）、快速前往各流程，并即时显示对应 PRD 章节与埋点事件。
前台
前台 Web（PC 落地页）
PC 浏览器只显示品牌落地页：Banner、产品介绍、扫码在手机打开，不提供登录与游戏。
后台
总后台
平台内部人员使用：仪表盘、用户、实名审核、充提与财务、俱乐部、牌桌与赛事、商品、VIP、内容、风控、报表、系统。
后台
派牌管理后台
牌局记录（每一手的发牌、行动与结算）、查询、稽核、异常牌局标记与调查。
后台
代理后台
以标签区分使用者：包网商户（本站用户、充提、报表、与平台结算）、合作代理（俱乐部成员、牌局、报表、分成明细）。
文档
PRD 文档
产品需求文档中心：00～15 份 PRD 摘要，含角色权限、资金模型、充提限额、盲注与抽水、赛事、VIP、后台权限、埋点与错误码表，可搜索。
文档
开发计划
2021 年德州扑克 WAP 开发计划示范：路线图甘特图、Sprint 与人力、里程碑、风险与依赖、Jira 看板与燃尽图、AI 辅助工作流、IPD × Scrum；附与 PRD / Demo 现况对照。
建议的体验路线
1. 前台 WAP 以「游客」身份 → 新人局打一手 → 结果页「绑定邮箱，加入牌局」完成绑定（邮箱验证码 000000，必须设置通行密钥）。
2. 切换「正式账号」→ 充值（订单处理中）→ 另开一个分页进入总后台「充提与财务」把订单设为成功 → 回前台看余额入账。
3. 现金桌入座带入 100～500BB，实际打几手（抽水 5% 封顶、时间银行、延时卡）→ 离桌结算。
4. 报名锦标赛（报名金额 + 10% 服务费）→ 模拟开赛 → 打到淘汰看名次与奖励。
5. 切换「俱乐部创建者」→ 俱乐部管理：开私人桌、管理员权限、关闭俱乐部（倒数 3 秒 → 邮箱验证码 → 通行密钥）。
6. 我的 → 防沉迷设置：设定冷静期后，再尝试充值或入座，会看到拦截提示。
